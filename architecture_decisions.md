# Architecture Decisions

## Why LangGraph?

The research process naturally consists of multiple independent tasks. LangGraph allows each task to be implemented as a separate agent, making the workflow modular, maintainable, and easier to extend.

## Why React?

React provides reusable UI components and enables an interactive dashboard experience.

## Why Node.js?

Node.js efficiently manages asynchronous API requests and integrates well with AI workflows.

## Why MongoDB?

MongoDB stores generated reports without requiring a rigid schema, making future extensions easier.
